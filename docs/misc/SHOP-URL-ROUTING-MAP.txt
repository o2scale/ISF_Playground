## 🔄 4. API ENDPOINTS SUMMARY

### Student/Public Endpoints

| Method | Endpoint | Permission | Description |
|--------|----------|------------|-------------|
| GET | `/api/v2/shop/products` | Authenticated | Get products with filters |
| GET | `/api/v2/shop/products/:id` | Authenticated | Get single product |
| GET | `/api/v2/shop/categories` | Authenticated | Get categories |
| GET | `/api/v2/cart` | Student | Get cart |
| POST | `/api/v2/cart` | Student | Add to cart |
| PUT | `/api/v2/cart/:id` | Student | Update cart item |
| DELETE | `/api/v2/cart/:id` | Student | Remove cart item |
| POST | `/api/v2/shop/checkout` | Student | Process checkout |
| GET | `/api/v2/shop/orders` | Student | Get order history |
| GET | `/api/v2/shop/orders/:id` | Student | Get order details |
| POST | `/api/v2/shop/orders/:id/cancel` | Student | Cancel order |
| GET | `/api/v2/transactions` | Authenticated | Get transactions |

### Coach Endpoints

| Method | Endpoint | Permission | Description |
|--------|----------|------------|-------------|
| GET | `/api/v2/shop/coach/deliveries` | Coach | Get pending deliveries |
| GET | `/api/v2/shop/coach/deliveries/stats` | Coach | Get delivery stats |
| PATCH | `/api/v2/shop/coach/deliveries/:orderId/deliver` | Coach | Mark as delivered |

### Admin Endpoints

| Method | Endpoint | Permission | Description |
|--------|----------|------------|-------------|
| GET | `/api/v2/shop/admin/products` | Shop Management: Manage | Get all products (admin view) |
| POST | `/api/v2/shop/admin/products` | Shop Management: Manage | Create product |
| PUT | `/api/v2/shop/admin/products/:id` | Shop Management: Manage | Update product |
| DELETE | `/api/v2/shop/admin/products/:id` | Shop Management: Manage | Delete product |
| POST | `/api/v2/shop/admin/inventory/bulk-update` | Shop Management: Manage | Bulk stock update |
| POST | `/api/v2/shop/admin/inventory/adjust` | Shop Management: Manage | Manual stock adjustment |
| GET | `/api/v2/shop/admin/stock/low` | Shop Management: Manage | Get low stock report |
| GET | `/api/v2/shop/admin/stock/out` | Shop Management: Manage | Get out of stock report |
| GET | `/api/v2/shop/admin/analytics` | Shop Management: Manage | Get analytics data |
| GET | `/api/v2/shop/admin/reports/transactions` | Shop Management: Manage | Get transaction reports |
| POST | `/api/v2/shop/products/:id/images` | Shop Management: Manage | Upload product images |
| DELETE | `/api/v2/shop/products/:id/images/:imageId` | Shop Management: Manage | Delete product image |
| PUT | `/api/v2/shop/products/:id/images/:imageId/primary` | Shop Management: Manage | Set primary image |

## 🚨 8. CRITICAL ISSUES IDENTIFIED

### Issue 1: Routes Not Registered ⚠️ HIGH PRIORITY

**Problem:** All admin and coach shop pages exist but routes are missing from `AppRoutes.js`

**Impact:**
- Admins cannot access Product Management, Inventory, Analytics, Reports
- Coaches cannot access Delivery Management
- Students cannot access Cart or Transaction History

**Affected URLs:**
- `/shop/cart`
- `/shop/transactions`
- `/coach/deliveries`
- `/shop/admin/products`
- `/shop/admin/inventory`
- `/shop/admin/stock/low`
- `/shop/admin/stock/out`
- `/shop/admin/analytics`
- `/shop/admin/reports/transactions`

**Solution:** Add all missing routes to `frontend/src/AppRoutes.js` (see Section 5)

---

### Issue 2: FloatingDeliveriesButton Not Integrated ⚠️ MEDIUM PRIORITY

**Problem:** Component exists but not rendered in Layout for coaches

**Impact:** Coaches cannot easily access delivery queue

**Solution:** Add conditional rendering in App.js or Layout.js:

```jsx
{user?.role === 'coach' && location.pathname.startsWith('/shop') && (
  <FloatingDeliveriesButton />
)}
```

---

### Issue 3: No Navigation Menu Links ⚠️ HIGH PRIORITY

**Problem:** Users have no way to discover or navigate to shop pages

**Impact:** Features are inaccessible through UI (only via direct URL)

**Solution:**
1. Add shop menu items to sidebar/navigation based on role
2. Update `frontend/src/components/Sidebar.jsx` or navigation component
3. Implement role-based menu visibility
