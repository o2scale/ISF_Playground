#### Technical Decisions Made

1. **Pages vs Modals**
   - Decision: Used full pages for order detail instead of modal
   - Reason: Better UX for complex information, easier navigation, better for receipt printing

2. **Toast Library**
   - Decision: Used react-hot-toast (already in project)
   - Reason: Avoided installing react-toastify, consistent with existing codebase

3. **Countdown Timer**
   - Implementation: useEffect with setInterval updating every second
   - Format: M:SS with leading zeros
   - Cleanup: Proper interval cleanup on unmount

4. **Backend Cancellation Time**
   - Changed: 24 hours → 5 minutes
   - Method: Updated virtual getter calculation from hours to minutes
   - Files: Model, service, controller for consistency

5. **Print Functionality**
   - Method: CSS `@media print` to hide buttons
   - Page margins: 1cm on all sides
   - Triggers: window.print() JavaScript API

### Lessons Learned

1. **Sync Frontend/Backend Times**
   - Ensured 5-minute window enforced in both backend model and frontend timer
   - Backend virtual getter and frontend canCancelOrder use same calculation

2. **Real-time Updates**
   - setInterval with 1-second intervals provides smooth countdown UX
   - Cleanup is critical to prevent memory leaks

3. **Library Choices**
   - Always check existing dependencies before adding new ones
   - react-hot-toast was already available, avoided react-toastify

4. **Page Architecture**
   - Full pages better than modals for complex features
   - Easier navigation, better for printing, better SEO

5. **Print CSS**
   - @media print crucial for receipt functionality
   - Hide UI buttons, adjust margins, clean formatting
